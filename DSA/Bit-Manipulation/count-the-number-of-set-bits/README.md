## 📝 Problem Statement

Given an integer **n** , return the number of set bits (1s) in its binary representation.

Can you solve it in **O(log n)** time complexity?

### Example 1

<p>

**Input:** n = 5</p><p>

**Output:** 2</p><p>

**Explanation:** The binary representation of 5 is 101, which has 2 set bits.</p>

### Example 2

<p>

**Input:** n = 15</p><p>

**Output:** 4</p><p>

**Explanation:** The binary representation of 15 is 1111, which has 4 set bits.</p>

### Constraints

- 0 ≤ n ≤ 10⁹

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
