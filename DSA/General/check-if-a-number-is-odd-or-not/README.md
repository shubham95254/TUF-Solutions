## 📝 Problem Statement

Given a non-negative integer n, determine whether it is odd.

Return true if the number is odd, otherwise return false.

A number is odd if it is not divisible by 2 **(i.e., n % 2 != 0)** .

### Example 1

<p>

**Input:** n = 7</p><p>

**Output:** true</p><p>

**Explanation:** 7 is not divisible by 2. Hence, it is odd.</p>

### Example 2

<p>

**Input:** n = 0</p><p>

**Output:** false</p><p>

**Explanation:** 0 is divisible by 2. Hence, it is not odd.</p>

### Constraints

- 0 <= n <= 10^4
