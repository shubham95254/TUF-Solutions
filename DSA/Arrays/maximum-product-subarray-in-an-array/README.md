## 📝 Problem Statement

Given an integer array **nums** . Find the **subarray** with the **largest product** , and return the **product** of the elements present in that **subarray** .

A **subarray** is a **contiguous** non-empty **sequence** of elements within an array.

### Example 1

<p>

**Input:** nums = [4, 5, 3, 7, 1, 2]</p><p>

**Output:** 840</p><p>

**Explanation:** </p>The largest product is given by the whole array itself

### Example 2

<p>

**Input:** nums = [-5, 0, -2]</p><p>

**Output:** 0</p><p>

**Explanation:** </p>The largest product is achieved with the following subarrays [0], [-5, 0], [0, -2], [-5, 0, -2].

### Constraints

- 1 <= nums.length <= 10^4
- -10 <= nums[i] <= 10
- -10^9 <= product of any prefix or suffix of nums <= 10^9

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
