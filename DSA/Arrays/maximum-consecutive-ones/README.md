## 📝 Problem Statement

Given a binary array **nums** , return the maximum number of consecutive 1s in the array.

A binary array is an array that contains only 0s and 1s.

### Example 1

<p>

**Input:** nums = [1, 1, 0, 0, 1, 1, 1, 0]</p><p>

**Output:** 3</p><p>

**Explanation:** </p>The maximum consecutive 1s are present from index 4 to index 6, amounting to 3 1s

### Example 2

<p>

**Input:** nums = [0, 0, 0, 0, 0, 0, 0, 0]</p><p>

**Output:** 0</p><p>

**Explanation:** </p>No 1s are present in nums, thus we return 0

### Constraints

- 1 <= nums.length <= 10^5
- nums[i] is either 0 or 1.
