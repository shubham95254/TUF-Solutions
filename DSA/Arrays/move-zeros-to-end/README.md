## 📝 Problem Statement

Given an integer array **nums** , move all the 0's to the end of the array. The relative order of the other elements must remain the same.

This must be done in place, without making a copy of the array.

### Example 1

<p>

**Input:** nums = [0, 1, 4, 0, 5, 2]</p><p>

**Output:** [1, 4, 5, 2, 0, 0]</p><p>

**Explanation:** </p>Both the zeroes are moved to the end and the order of the other elements stay the same

### Example 2

<p>

**Input:** nums = [0, 0, 0, 1, 3, -2]</p><p>

**Output:** [1, 3, -2, 0, 0, 0]</p><p>

**Explanation:** </p>All 3 zeroes are moved to the end and the order of the other elements stay the same

### Constraints

- 1 <= nums.length <= 10^5
- -10^4 <=nums[i] <= 10^4

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
